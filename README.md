# Бот-викторина для Исторического музея

Чат-бот для проведения викторины по истории. Поддерживает Telegram и ВКонтакте. 
Бот задает каверзные вопросы, проверяет ответы, ведет счет и позволяет сдаться, если вопрос слишком сложный.

## Ссылки на ботов
- **Telegram:** [Ссылка на твоего бота в Telegram](https://t.me/Holding_a_quiz_bot)
- **ВКонтакте:** [Ссылка на сообщество в ВК](https://vk.com/club241174441)


## Окружающая среда 

Проект разработан и протестирован в следующем окружении:
- Python 3.10+
- Redis (внешнее хранилище для состояния пользователей и счета)
- Виртуальное окружение (`venv`)

## Зависимости

Для работы проекта необходимы следующие библиотеки. Их список находится в файле `requirements.txt`:
- `python-telegram-bot==21.6`
- `python-dotenv==1.0.1`
- `redis==5.0.1`
- `vk-api==11.9.9`

## Переменные окружения

Для запуска ботов необходимо создать в корневой папке проекта файл `.env` и заполнить его следующими переменными:

```env
TELEGRAM_BOT_TOKEN=ваш_токен
VK_GROUP_TOKEN=ваш_токен
VK_GROUP_ID=ваш_id
REDIS_HOST=ваш_хост
REDIS_PORT=ваш_порт
REDIS_PASSWORD=ваш_пароль
```

## Как получить токены

- TELEGRAM_BOT_TOKEN: Создайте нового бота через @BotFather в Telegram и скопируйте выданный токен.
- VK_GROUP_TOKEN: В управлении сообществом ВКонтакте перейдите в раздел `Работа с API` -> `Ключи доступа`. Создайте ключ с правами Сообщения и Управление.
- VK_GROUP_ID: Числовой ID вашего сообщества. Его можно увидеть в адресной строке браузера при переходе в группу (например, `vk.com/club123456789`, где `123456789` — это ID).
- REDIS_HOST, REDIS_PORT, REDIS_PASSWORD: Зарегистрируйте бесплатную базу данных на [Redis Cloud (Redis Labs)](https://redis.com/try-free/?spm=a2ty_o01.29997173.0.0.5a5155fbJL1JHp). Данные для подключения будут указаны в разделе Configuration созданной базы.


## Как запустить локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Equ17y/lesson_4_quiz_bot.git
   cd lesson_4_quiz_bot
   ```

2. Создайте виртуальное окружение и установите зависимости:
    ```bash
    python -m venv venv
    # Для Windows:
    venv\Scripts\activate
    # Для macOS/Linux:
    source venv/bin/activate
    ```

3. Установите зависимости: 
    ```bash    
    pip install -r requirements.txt
    ```   

4. Создайте файл .env и заполните его переменными:
    ```env
    TELEGRAM_BOT_TOKEN=ваш_токен
    VK_GROUP_TOKEN=ваш_токен
    VK_GROUP_ID=ваш_id
    REDIS_HOST=ваш_хост
    REDIS_PORT=ваш_порт
    REDIS_PASSWORD=ваш_пароль
    ```

4. Запустите ботов:
    ```bash
    python telegram_bot.py
    python vk_bot.py
    ```    

## Примечание

- Умная проверка ответов: Бот игнорирует регистр, лишние пробелы, текст в круглых скобках и пояснения после точки в правильном ответе (например, ответ "Москва" засчитается для "Москва. Столица России (осн. в 1147)").
- Архитектура: Логика Telegram-бота построена на ConversationHandler (машина состояний), а VK-бота — на обработке событий Long Polling.
- Деплой: Для постоянной работы на VDS-сервере используются systemd сервисы с автоматическим перезапуском (Restart=always).
